Решение проблем

Каждая запись — реальная ошибка этого проекта с конкретным фиксом. Ничего спекулятивного.

WinError 32 — сборка не может удалить БД (Windows)

Симптом: PermissionError: [WinError 32] The process cannot access the file because it is being used by another process: 'wiki.db'

Фикс: forge.py db_connect(recreate=True) теперь сначала удаляет stale WAL/SHM sidecar и при заблокированном файле падает обратно на сброс схемы на месте. Зафиксировано в коде путей пересборки.

FTS5 был тихо отключён при первой сборке

Симптом: no such column: T.headings

Причина: FTS5 был объявлен как external-content таблица поверх docs, у которого нет колонки headings.

Фикс: отдельная standalone-таблица docs_fts; теперь поиск на самом деле работает.

Падение cp1252 на Windows для не-ASCII вывода

Симптом: UnicodeEncodeError: 'charmap' codec can't encode character '\u25b8'

Фикс: sys.stdout.reconfigure(encoding='utf-8') в скриптах; статус-символы убраны.

Сайт отдавал 404 на Pages-адресе

Причина: источник Pages был main / (корень), тогда как сайт жил в /docs.

Фикс: gh api ... -X PUT -f source[path]=/docs. Подтверждено: сборка built, страница отдаёт 200.

Отсутствующий favicon / og-card

logo.svg ссылался, но файла не было; og-card.jpg заявлялся в meta, но не был закоммичен. Сгенерированы и закоммичены.

GitHub Actions заблокирован биллингом

Симптом: The job was not started because your account is locked due to a billing issue.

Фикс: реальная проверка — локальный гейт (python brain/scripts/verify.py), 12 гейтов, ненулевой код выхода при провале. CI не доказан, пока биллинг не исправят; зелёным его считать нельзя.

F008 sync заблокирован

Файл воркфлоу есть (n8n-wiki/workflows/f008-sync-workflow.json); нужен запущенный n8n для webhook/cron-проверки. Заблокирован окружением, не дизайном.
