Начало работы

Четыре команды отделяют холодную машину от проверенного ответа по 688 466 словам документации n8n.

1. Клонировать репозиторий

git clone https://github.com/homgorn/n8n-saas-factory.git
cd n8n-saas-factory

2. Клонировать исходники документации n8n

Вики строится из GitBook-источника n8n-io/n8n-docs (достаточно поверхностного клонирования):

git clone --depth 1 https://github.com/n8n-io/n8n-docs.git n8n-docs-source

Это ~100 МБ и Sustainable Use License — мы внедряем только как справочный материал, без перераспространения. Папка исключена из git и из MIT-лицензии LICENSE.

3. Построить вики и проверить гейт

python brain/scripts/forge.py build
python brain/scripts/verify.py            # ожидайте VERDICT: PASS, 12/12

4. Запросить вики

python brain/scripts/query.py ask "how do I paginate API results"

Верхним ответом будет документация HTTP Request node | Pagination с кодом и цитатами. Для самого SaaS нужен собственный n8n клиента (ADR-001): анализатор и генератор работают с импортированным JSON воркфлоу.

Требования

  • Python 3.10+ (для forge сторонних пакетов не нужно)
  • ~1,5 ГБ свободного места под клонирование и построенную вики
  • Гейт пересобирает всё из источника, кэш между запусками не используется

Ограничения

  • Векторного поиска нет — поиск — SQLite FTS5 + IDF с весом заголовка
  • F008 (sync) и F009 (Playwright) требуют запущенного n8n и развёрнутого preview соответственно
