Справочник CLI

Все команды запускаются из корня репозитория с Python 3.10+. forge работает только на stdlib.

forge.py — сборка и поиск по вики

python brain/scripts/forge.py build        # полная пересборка (идемпотентна)
python brain/scripts/forge.py stats        # форма корпуса
python brain/scripts/forge.py query "pagination"    # полнотекстовый поиск по страницам
python brain/scripts/forge.py ask "retry failed executions error handling"

query.py — структурированные ответы

python brain/scripts/query.py ask "how do I paginate API results"
python brain/scripts/query.py query "pagination"
python brain/scripts/query.py classify "what parameters does the Slack node have"
python brain/scripts/query.py --format json ask "queue mode redis scaling"

analyzer.py — анализ воркфлоу

python brain/scripts/analyzer.py --all                 # проанализировать все воркфлоу из доков
python brain/scripts/analyzer.py <workflow.json> --format json
python brain/scripts/analyzer.py <workflow.json> --format md

Текущий результат на Google Sheets (docs version): найден один AI-агент (@n8n/n8n-nodes-langchain.agent), модель разрешилась в lmChatOpenAi, сложность 9/10.

generator.py — spec → SaaS-проект

python brain/scripts/generator.py brain/research/workflow-analyses/agents-vs-chains.json -o generated-saas
python brain/scripts/generator.py --all -o generated-saas

verify.py — гейт

python brain/scripts/verify.py            # 12 гейтов, печатает VERDICT
python brain/scripts/verify.py --quick    # пропустить гейты, зависящие от пересборки

Гейты: sources present, wiki rebuild is idempotent, corpus floor, every page has a standalone summary, every page resolves to a live source URL, retrieval answers a real question, workflow analyzer detects AI agents, query interface answers real questions, claims are typed and sourced, no secrets committed, licence position is documented, feature list is honest.

seed_claims.py — claims с првенансом

python brain/scripts/seed_claims.py
