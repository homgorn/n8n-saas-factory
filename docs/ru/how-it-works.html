Как это устроено

Каждый компонент либо проверен локально гейтом, либо заблокирован известным лицензионным ограничением. Слоя «просто поверьте мне» нет.

Конвейер

n8n-docs-source/docs/  (GitBook-источник)
        │  forge.py — разбиение, извлечение сущностей, запись вики
        ▼
brain/wiki/<topic>/<slug>.md  +  brain/data/wiki.db
        │  query.py ask  — FTS5 + IDF, цитаты, JSON
        ▼
brain/scripts/analyzer.py  — JSON воркфлоу → spec
brain/scripts/generator.py — spec + шаблон → SaaS-проект
        │  verify.py — 12 гейтов
        ▼
GitHub Actions: .github/workflows/verify.yml  (заблокирован биллингом; реальная проверка — локальный гейт)

12 гейтов

  • sources present
  • wiki rebuild is idempotent
  • corpus floor
  • every page has a standalone summary
  • every page resolves to a live source URL
  • retrieval answers a real question
  • workflow analyzer detects AI agents
  • query interface answers real questions
  • claims are typed and sourced
  • no secrets committed
  • licence position is documented
  • feature list is honest

Лицензионная архитектура (ADR-001)

Sustainable Use License не разрешает предоставлять n8n третьим лицам для прибыли. Поэтому продукт обращается к n8n-инстанции, которым владеет клиент, через публичный REST API с ключом, выданным клиентом. Мы не хостим и не перепродаём движок; генерируемый SaaS — это дашборд, биллинг и наблюдаемость, а движок остаётся у клиента.

Claims с првенансом

На страницы допускаются только типизированные утверждения: measured (запущено, артефакт указан), reported (источник говорит так, URL + дата), inferred (вывод с рассуждением), unconfirmed (искал, не нашёл). Сейчас 11 claims в brain/index/claims.json, они переприменяются при каждой пересборке.
