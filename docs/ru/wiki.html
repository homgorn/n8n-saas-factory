Вики

Регенерируемая база знаний по документации n8n: 1348 страниц, 9,578 фрагментов, 688,466 слов, 11 доменов, 12 импортируемых воркфлоу, 2,966 сущностей, 2,552 триплетов.

Чем она не является

Это не документация для людей. Это поиск для «холодного» агента, у которого нет истории чата. Каждая страница несёт самодостаточное summary ≤ 200 символов.

Четыре уровня индекса

  1. brain/INDEX.md — домены
  2. brain/wiki/<topic>/00-INDEX.md — страницы домена
  3. brain/wiki/<topic>/<slug>.md — файл на страницу с YAML front-matter
  4. brain/index/topics.json — машинный индекс с summary и URL источника

Пересборка

python brain/scripts/forge.py build      # полная пересборка (идемпотентна)
python brain/scripts/forge.py stats      # форма корпуса

Примеры запросов

python brain/scripts/query.py ask "how do I paginate API results"
python brain/scripts/query.py query "pagination"
python brain/scripts/query.py classify "why does my workflow fail"
