The wiki

A regenerable knowledge base over the n8n documentation: 1348 pages, 9,578 chunks, 688,466 words, 11 domains, 12 importable workflows, 2,966 entities, 2,552 triples.

What it is not

It is not documentation for humans. It is retrieval for a cold agent that has no chat history and no prior knowledge of the project. Every page carries a ≤200-character summary that stands alone.

Four levels of index

  1. brain/INDEX.md — domains
  2. brain/wiki/<topic>/00-INDEX.md — pages under each domain
  3. brain/wiki/<topic>/<slug>.md — one file per page with YAML front-matter
  4. brain/index/topics.json — machine index with summaries and source URLs

Regeneration

python brain/scripts/forge.py build      # rebuild from n8n-docs-source/docs/
python brain/scripts/forge.py stats      # corpus shape

Query examples

python brain/scripts/query.py ask "how do I paginate API results"
python brain/scripts/query.py query "pagination"
python brain/scripts/query.py classify "why does my workflow fail"
