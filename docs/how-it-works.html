How it works

Every component is either verified locally by the gate, or blocked by a known licence constraint. There is no “trust me” layer.

The pipeline

n8n-docs-source/docs/  (GitBook source)
        │  forge.py — chunk, extract entities, write wiki
        ▼
brain/wiki/<topic>/<slug>.md  +  brain/data/wiki.db
        │  query.py ask  — FTS5 + IDF, citations, JSON
        ▼
brain/scripts/analyzer.py  — workflow JSON → spec
brain/scripts/generator.py — spec + template → SaaS project
        │  verify.py — 12 gates
        ▼
GitHub Actions: .github/workflows/verify.yml  (billing-locked; the local gate is what actually proves it)

The 12 gates

  • sources present
  • wiki rebuild is idempotent
  • corpus floor
  • every page has a standalone summary
  • every page resolves to a live source URL
  • retrieval answers a real question
  • workflow analyzer detects AI agents
  • query interface answers real questions
  • claims are typed and sourced
  • no secrets committed
  • licence position is documented
  • feature list is honest

Licence architecture (ADR-001)

n8n’s Sustainable Use License does not permit providing n8n to third parties for profit. The product therefore calls a n8n instance the customer operates, via its public REST API with a key the customer supplies. We never host, mirror, or resell the engine; the SaaS we generate is a dashboard, billing plumbing and observability — the engine is the customer’s.

Provenance claims

Only typed claims reach documentation: measured (ran it, artifact named), reported (a source says so, URL + retrieval date), inferred (reasoned, reasoning written out), unconfirmed (looked for it, not found). 11 claims currently exist in brain/index/claims.json and are re-applied on every rebuild.
