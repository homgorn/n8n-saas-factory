What's built

Every deliverable is verified by the gate in brain/scripts/verify.py. Nothing is marked "done" on the agent's own say.

📚

LLM Wiki over n8n docs

Four-level indexed knowledge base from the official GitBook source. 1,348 pages, 9,578 chunks, searchable by FTS5, queryable via CLI.

🔍

Query interface

Natural-language questions return structured answers: citations, code examples, related workflows, next steps. Classification: how-to, node-ref, troubleshooting, architecture, best-practice.

🧩

Workflow analyzer

Reads workflow JSON, detects AI agents, trigger types, data flow, credentials, estimates complexity (0–10) and outputs the spec the generator consumes.

⚙️

SaaS template (AI Tool)

Next.js 14 App Router, Clerk auth, Supabase database, Stripe billing, n8n REST client, webhook handler with HMAC verification, dashboard and landing.

🤖

Agent orchestration

Seven specialized agents through OpenChamber: explorer, researcher, architect, implementer, verifier (mandatory), reviewer, runner. Routing table in AGENTS.md.

🔒

Verification gate

12 automated gates: build idempotence, corpus floor, summaries within 200 chars, live URLs, retrieval accuracy, provenance claims, secrets scan, licence documentation, feature list honesty, query interface, workflow analyzer.

Agent roles

Every subagent needs a distinct job. Two agents with the same prompt are one agent.

explorer

Read-only mapping. Cheap model. "Where is X?"

researcher

Search the wiki, docs, web. No writes.

architect

Design SaaS from workflow. Writes SPEC.md.

implementer

Writes code. One feature at a time. No stubs, no TODOs.

verifier

Mandatory before PASS. Read-only. Never fixes. Blocked ≠ Pass.

reviewer

Thermo-nuclear review: security, correctness, maintainability.

runner

Runs builds. Reports only failures.

What is done and what remains

Every feature is verifiable independently by a human with no memory of the project.
