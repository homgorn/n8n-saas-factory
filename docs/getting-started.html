Getting started

Four commands separate a cold machine from a verified query over 688,466 words of n8n documentation.

1. Clone the repository

git clone https://github.com/homgorn/n8n-saas-factory.git
cd n8n-saas-factory

2. Clone the n8n documentation source

The wiki is built from the GitBook source at n8n-io/n8n-docs (a shallow clone is enough):

git clone --depth 1 https://github.com/n8n-io/n8n-docs.git n8n-docs-source

This is ~100 MB and carries n8n’s Sustainable Use License — we vendor, we don’t redistribute. It is excluded from tracked files and from the licence grant in LICENSE.

3. Build the wiki and verify the gate

python brain/scripts/forge.py build
python brain/scripts/verify.py            # expect VERDICT: PASS, 12/12 gates

4. Query it

python brain/scripts/query.py ask "how do I paginate API results"

Top hit is the HTTP Request node pagination docs. The answer includes citations and a code path. Bring your own n8n instance (the customer’s) to build the actual SaaS — the analyzer and generator work on imported workflow JSON.

Requirements

  • Python 3.10+ (no third-party packages for the forge)
  • ~1.5 GB free disk for the clone and built wiki
  • The gate rebuilds everything from source; nothing is cached between runs

Known limits

  • No vector search — retrieval is SQLite FTS5 + IDF with heading boosts
  • F008 sync workflows and F009 Playwright smoke tests require a running n8n instance and a deployed preview; see CLI and Troubleshooting
