Troubleshooting

Every entry below is an error this project has actually hit, the evidence it is real, and the fix that stuck. Nothing here is speculative.

WinError 32 — the build could not unlink the database (Windows)

Symptom: PermissionError: [WinError 32] The process cannot access the file because it is being used by another process: 'wiki.db'

Fix: forge.py db_connect(recreate=True) now deletes stale WAL/SHM sidecars first, and falls back to dropping the schema in place when the file is locked. Committed with the rebuild-from-scratch path.

FTS5 was silently disabled on first build

Symptom: no such column: T.headings

Cause: FTS5 was declared as an external-content table over docs, which has no headings column.

Fix: standalone docs_fts table; page-level search actually runs now.

cp1252 crash on Windows for non-ASCII output

Symptom: UnicodeEncodeError: 'charmap' codec can't encode character '\u25b8'

Fix: sys.stdout.reconfigure(encoding='utf-8') in the scripts and box-drawing characters removed from Status.

Site served 404 at the Pages URL

Cause: Pages source was set to main / (repo root), but the site lived in /docs.

Fix: gh api ... -X PUT -f source[path]=/docs. Confirmed 200 via build status and a fetched page.

Missing favicon / og:card image

logo.svg was referenced but never existed; og-card.jpg was declared in meta but not committed. Generated and committed.

GitHub Actions is billing-locked

Symptom: The job was not started because your account is locked due to a billing issue.

Fix: the local gate (python brain/scripts/verify.py) is what actually proves correctness — 12 gates, exit code non-zero on failure. CI is unproven until billing is resolved; do not assume green.

F008 sync workflows blocked

The n8n workflow file exists (n8n-wiki/workflows/f008-sync-workflow.json); it needs a running n8n instance for webhook/cron verification. Environment-blocked, not design-blocked.
